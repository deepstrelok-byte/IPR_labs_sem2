# Развертывание микросервисного приложения в Kubernetes (Лабораторная работа №5)

Этот репозиторий содержит все необходимые файлы для развертывания приложения из лабораторной работы №4 в локальном кластере Kubernetes (Docker Desktop).

## Архитектура приложения

Приложение состоит из следующих компонентов, развернутых в Kubernetes:
*   `user-service`: Основной сервис, предоставляющий API.
*   `stats-service`: Сервис для фоновой обработки статистики.
*   `PostgreSQL`: База данных.
*   `Redis`: Кэш.
*   `RabbitMQ`: Очередь сообщений.
*   `Ingress`: Nginx Ingress Controller для маршрутизации внешнего трафика.
*   `HPA`: Horizontal Pod Autoscaler для автоматического масштабирования `user-service`.

## Как запустить

**Пререквизиты:**
*   Установлен Docker Desktop с включенным Kubernetes.
*   Установлен `kubectl`.

**Порядок действий:**

1.  **Клонировать репозиторий:**
    ```bash
    git clone https://github.com/ВАШ_НИК/ИМЯ_РЕПОЗИТОРИЯ.git
    cd ИМЯ_РЕПОЗИТОРИЯ
    ```

2.  **Собрать локальный Docker-образ:**
    *   Образ собирается с тегом `:v1`, который уже прописан в манифестах.
    ```bash
    docker build -t lab-app:v1 .
    ```

3.  **Развернуть все компоненты в Kubernetes:**
    *   Эта команда последовательно применит все манифесты из папки `k8s/`.
    ```bash
    kubectl apply -f k8s/
    ```
    *   **Важно:** Установка Ingress Controller и Metrics Server — это разовые операции, которые выполняются отдельно и не включены в эти манифесты.

4.  **Настроить доступ по доменному имени:**
    *   Добавьте следующую строку в ваш файл `hosts` (`/etc/hosts` на Mac/Linux, `C:\Windows\System32\drivers\etc\hosts` на Windows):
    ```
    127.0.0.1 app.lab5.local
    ```

5.  **Проверить доступ к приложению:**
    *   Откройте в браузере [http://app.lab5.local](http://app.lab5.local). Вы должны увидеть `{"message":"User Service is running!"}`.

6.  **Проверить автомасштабирование (HPA):**
    *   В одном терминале запустите наблюдение:
        ```bash
        kubectl get hpa -n lab5 -w
        ```
    *   Во втором терминале создайте нагрузку:
        ```bash
        while true; do curl http://app.lab5.local/; done
        ```
    *   Наблюдайте, как количество реплик `user-service` увеличивается.

## Основные этапы отладки

В процессе развертывания были решены следующие типовые проблемы:
*   **`ImagePullBackOff`:** Исходная проблема с приватными образами на GHCR была решена переходом на локальную сборку.
*   **`EOFError` в логах:** Проблема была вызвана наличием `input()` в коде, который ждал интерактивного ввода. Решено полным рефакторингом `main.py` для запуска в режиме веб-сервера.
*   **`ModuleNotFoundError`:** Проблема отсутствия `fastapi` и `uvicorn` была решена их добавлением в `requirements.txt`.
*   **Проблема с кэшированием образа:** Необновляемый образ в Docker Desktop был "побежден" использованием версионированных тегов (`:v1`, `:v2`...).
*   **Ошибки Ingress и Metrics Server:** Проблемы решены ожиданием полной готовности подов и добавлением флага `--kubelet-insecure-tls` для Metrics Server в среде Docker Desktop.
